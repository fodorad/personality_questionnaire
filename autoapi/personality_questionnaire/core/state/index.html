personality_questionnaire.core.state¶

Application state.

Two layers, kept apart on purpose:

  • AppState is process-wide – the record store and the cached listing that every browser connection shares.

  • DraftRecord is per-connection: one participant part-way through one questionnaire. Two browser tabs are two independent drafts.

All the logic the interface needs lives here rather than in pages/: progress, completeness, which items remain. That is what lets the page modules stay thin element-building code, and it is why they are excluded from coverage while this module is tested directly.

load_from(record: personality_questionnaire.db.Record, *, read_only: bool = True) → None[source]¶

Populate every field from a stored record, for viewing or editing.

Replaces the draft’s participant identity, instrument, responses, tag, experiment and notes with the record’s own, and remembers record.session_id so a later save updates that session instead of inserting a new one.

Parameters:

  • record – The stored record to load.

  • read_only – Whether the draft should render inert until explicitly unlocked. Defaults to True: a loaded record is always viewed before it can be edited.

Raises:

ValueError – If record.session_id is None – an unsaved record cannot be “loaded back”.

unlock() → None[source]¶

Allow a loaded draft to be edited.

Identity fields (participant, instrument, tag) are not re-exposed by this alone – the questionnaire tab is the only place an unlocked draft is edited, and it never shows those fields – this just clears the flag that keeps answers from being changed.

records() → list[personality_questionnaire.db.RecordSummary][source]¶

Return every stored record, newest first.

Read fresh every time rather than cached. The database is shared – the CLI writes to it, and a second machine may too – so a cached listing goes stale the moment anything outside this process saves a record, and showing an operator “no records yet” when the database holds several is worse than the cost of a query against a table this size.

Returns:

The stored records.

set_database(url: str) → None[source]¶
