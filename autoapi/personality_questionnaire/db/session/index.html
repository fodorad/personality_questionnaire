personality_questionnaire.db.session¶

Engine and session management.

The database URL comes from PQ_DATABASE_URL, defaulting to a SQLite file under the user’s home directory so a lab machine needs no server and no configuration.

There are no migrations. The schema has one version, and a research tool that owns its own database is better served by an explicit export and re-import than by a migration graph nobody exercises. This is a decision, not an omission: see docs/storage.md.
